# 🧠 Orbe

Orbe is a mobile app focused on **habit tracking and daily task management**, designed to help you build consistency, discipline, and clarity in your routine.

The idea is simple: **what you do every day shapes who you become**.

---

## 🚀 Features

### ✅ Habit Tracking

* Create and manage habits
* Track daily completion
* Build consistency over time

### 📋 Daily Tasks

* Add and manage daily tasks
* Stay focused on what matters today
* Simple and distraction-free workflow

### 📊 Completion History

* View completed habits and tasks
* Track your progress over time

### 🔥 Streak System

* Track your longest habit completion streak
* Stay motivated by maintaining consistency

---

## 🛠️ Tech Stack

* React Native (Expo)
* TypeScript
* Zustand (state management)
* React Navigation

---

## 📱 Platforms

* iOS
* Android
* Web (via Expo)

---

## ⚙️ Getting Started

```bash
# install dependencies
npm install

# start the project
npm start

# run on specific platforms
npm run android
npm run ios
npm run web
```

---

## 🎯 Purpose

Orbe is not just a task manager.

It’s a tool to help you stay consistent, reduce distractions, and focus on what truly matters in your daily life.
